# 厚德公文对标库

> 9 万+ 篇政府依法主动公开的公文检索 · 公文格式自查与措辞工具

- **品牌与总入口**：https://gwhub.cn/

- **公文格式自查（开源）**：https://github.com/gwhub-cn/gw-checkup

## 这是什么

把各级政府门户网站「政府信息公开」栏目依法主动公开的公文，整理成可检索、可溯源的范文库。
每条记录含标题、发文机关、发文字号、发布日期与政府官网原文出处。

写材料前先看同一件事别人怎么写；写完能核对格式；每篇都能点回政府官网核验。

## 合规边界

- 依据《著作权法》第五条，国家机关的决议、决定、命令等文件不适用著作权法。
- 采集遵守 robots 协议、低频友好；不含任何未公开或涉密内容。
- 权利人可来信说明具体篇目，我们 24 小时内核实处理。
